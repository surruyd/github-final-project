# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Open an issue to discuss a significant change before starting work.
2. Fork the repository and create a focused branch for your change.
3. Make the change and test it locally.
4. Commit your work with a clear, descriptive commit message.
5. Open a pull request describing the change and any testing performed.

Please keep changes focused, write clear documentation, and be respectful in project discussions.
